name: issue
description: ビジネス職・PM・デザイナーなど非エンジニアが、エンジニアに依頼したい機能要望や改善要望を GitHub Issues に起票するのを支援する。やりたいことの背景 (困りごと・要望) と参考資料を対話的にヒアリングし、エンジニアが設計・タスク分解できるようにする。使い方: /dev:issue {タスクページのURLや作成したい内容のプロンプト}
model: sonnet
---

要件や使用をヒアリングし、エンジニアが作業を開始できるように Issue を作成してください。
Issue は FastShip プラグインの `${CLAUDE_PLUGIN_ROOT}/templates/ISSUE_TEMPLATE/backlog.md` に沿って起票してください。③ 課題分析がこの欄に追記するため、起票先リポジトリのテンプレートではなく、常にこれを使います。

 - 先頭の YAML frontmatter (`---` で囲んだ部分) は本文に含めないでください。
 - 起票時に書くのは 背景 と 参考資料 です。課題 / 解決策 / 成功指標 は ③ 課題分析が書くので、空のまま残してください。
